কীভাবে চালাবে: ← → কী বা নিচের বোতাম দিয়ে স্লাইড বদলাও। প্রতিটি পেজে নিজে চালানো যায় এমন অ্যানিমেশন আছে।
পাঠক্রম: Complexity · Search · Sorting · Stack/Queue · Linked List · Tree/BST · AVL · Hashing · Graph · Model Test (৩০টি random প্রশ্ন)

এই সাইট কীভাবে পড়বে

  1. স্লাইড পড়ো: প্রতি পেজে আগে বাংলা ব্যাখ্যা ও সংজ্ঞা। ← → কী বা নিচের বোতামে স্লাইড বদলাবে।
  2. অ্যানিমেশন নিজে চালাও: প্রতিটি ছবির পাশে “বাংলায় ব্যাখ্যা” কার্ড আছে — বোতাম চেপে ধাপগুলো মিলিয়ে দেখো।
  3. অনুশীলন প্রশ্ন: প্রতি পেজের শেষে সেই বিষয়ের প্রশ্ন; উত্তর বেছে নিলেই ব্যাখ্যা আসবে।
  4. Model Test: সবশেষে ৩০টি random প্রশ্ন, Shuffle করে বারবার দিতে পারবে।
প্রস্তাবিত ক্রম: Complexity → Search → Sorting → Stack/Queue → Linked List → Tree/BST → AVL → Hashing → Graph → Model Test।
রঙের অর্থ: হলুদ = এখন তুলনা/ভিজিট হচ্ছে; সবুজ = সম্পন্ন/পাওয়া গেছে; নীল = সক্রিয় সীমা বা সাধারণ অবস্থা; ধূসর = বাদ পড়া অংশ।

Data Structure কী?

Data সাজিয়ে রাখার ও ব্যবহারের পদ্ধতি। Linear: Array, Stack, Queue, Linked List। Non-linear: Tree, Graph।

Data Structure ও Algorithm একে অপরের সাথে যুক্ত — সঠিক structure বেছে নিলে algorithm দ্রুত হয়।
