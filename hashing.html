Hashing — বাংলায় ধারণা

অনেক data-র মধ্যে একটা খুঁজতে হলে সাধারণত তুলনা করতে হয়। Hashing-এ একটি hash function key-কে সরাসরি একটি ছোট সংখ্যা (index) বানিয়ে দেয়, আর data সেই index-এর bucket-এ রাখা হয়। ফলে খোঁজার সময় n-এর ওপর নির্ভর করে না — গড়ে O(1)।

Hash function: Division (key mod m), Mid-square (key² এর মাঝের অংশ), Folding (key ভেঙে যোগ)। ভালো function দ্রুত হয়, collision কম করে, key সমানভাবে ছড়ায়।
Collision: দুটি key একই bucket-এ পড়লে। সমাধান: Separate chaining (bucket-এ linked list) বা Open addressing (table-এর ভেতরেই খালি জায়গা খোঁজা): Linear (h+i), Quadratic (h+i²), Double (h+i·hash2)।

উদাহরণ: keys 50, 700, 76, 85, 92, 73, 101 — hash = key mod 7

mod 7: 50→1, 700→0, 76→6, 85→1, 92→1, 73→3, 101→3 (85, 92, 101 collision)।

Quadratic: 85→1, 1+1=2 ✔। 92→1, 2 ভরা, 1+4=5 ✔। 101→3 ভরা, 3+1=4 ✔।
Double: 85→h2=5, 1+5=6 ভরা, 1+10=11 mod 7=4 ✔। 92→h2=3: 4 ভরা, 7 mod 7=0 ভরা, 10 mod 7=3 ✔। 73→h2=2: 5 ✔। 101→h2=4: 0,4,1,5 সবই ভরা, 23 mod 7=2 ✔।
