Searching — খোঁজার কৌশল

কম্পিউটার প্রোগ্রামিংয়ের দুটি দিক: (১) data সাজিয়ে রাখা (data structure) এবং (২) সঠিক algorithm বেছে সমস্যা সমাধান। Searching হলো কোনো element data-র কোন অবস্থানে আছে তা বের করা। দুটি প্রধান পদ্ধতি:

১. Linear (Sequential) search — শুরু থেকে এক এক করে দেখা; list sorted না হলেও চলে।
২. Binary search — sorted list-এর মাঝখানে দেখে প্রতিবার অর্ধেক বাদ দেওয়া।
যা সাজানো আছে তা খোঁজা সহজ: দোকানে পোশাক size/দামে সাজানো, শ্রেণিকক্ষে নাম বর্ণানুক্রমে, লাইব্রেরিতে বই বর্ণানুক্রমে — এজন্য sorting ও searching একসাথে শেখা হয়।

Linear Search

List (ordered বা unordered) শুরু থেকে এক এক করে দেখা হয়, কাঙ্ক্ষিত element পাওয়া গেলে search সফল, নইলে ব্যর্থ। কতগুলো তুলনা লাগবে তা element কোথায় আছে তার ওপর নির্ভর করে: প্রথমে থাকলে ১টি, দ্বিতীয়ে ২টি, … গড়ে প্রায় (n+1)/2টি; না থাকলে n-টিই। Time complexity: O(n)।

linsrch(a[n], x){
  index = 0; flag = 0;
  while (index < n) do {
     if (x == a[index]) { flag = 1; break; }
     index++;
  }
  if (flag == 1) "found" else "not found" }
উদাহরণ ১: unsorted list 45 39 8 54 77 38 24 16 4 7 9 20। নিচে যেকোনো মান বেছে খুঁজে দেখো কত তুলনা লাগে।

উদাহরণ ২: index 0..8-এ −15 −6 0 7 9 23 54 82 101। x=7 ⇒ index 3-এ পাওয়া যায় (সফল); x=82 ⇒ index 7-এ (সফল); x=42 ⇒ পাওয়া যায় না (ব্যর্থ, ৯টি তুলনা)।

Linear search-এর C program

/* non-recursive */
for(i = 0; i < n; i++){ if(number[i] == data){ flag = 1; break; } }
if(flag == 1) printf("Data found at location: %d", i+1);
else          printf("Data not found");

/* recursive */
void linear_search(int a[], int data, int position, int n){
  if(position < n){
     if(a[position] == data) printf("Data Found at %d", position);
     else linear_search(a, data, position+1, n);
  } else printf("Data not found"); }
Recursive সংস্করণ প্রতিবার position ১ বাড়িয়ে নিজেকে ডাকে; position n ছুঁলে (base case) “not found”। সময় একই O(n), তবে recursion-এ call stack ব্যবহার হয়।

Binary Search

List অবশ্যই sorted। মাঝের ঘর (mid) দেখি: a[mid] = x হলে পেলাম; x < a[mid] হলে শুধু বামের অংশে, x > a[mid] হলে শুধু ডানের অংশে খুঁজি। প্রতিবার অর্ধেক বাদ পড়ে, তাই n কে ২ দিয়ে ভাগ করতে করতে ১-এ পৌঁছাতে প্রায় log₂n ধাপ লাগে ⇒ O(log n) (সফল ও ব্যর্থ দুই ক্ষেত্রেই)।

binsrch(a[], n, x){
  low = 1; high = n;
  while (low <= high) do {
     mid = (low + high)/2
     if (x < a[mid]) high = mid − 1;
     else if (x > a[mid]) low = mid + 1;
     else return mid;
  }
  return 0; }
প্রতি ধাপে low বাড়ে অথবা high কমে — দুটি সংখ্যা পরস্পরের দিকে এগোয় এবং শেষে low > high হলে element নেই বোঝা যায়।

Binary search অ্যানিমেশন

কীভাবে চালাবে: মান লিখে “শুরু” চাপো, তারপর “পরের ধাপ” চাপতে থাকো। হলুদ = mid; ঝাপসা = বাদ পড়া অংশ; সবুজ = পাওয়া গেছে। নিচে প্রতি ধাপের low/high/mid ও সিদ্ধান্ত লেখা হবে।

Binary search-এর C program

/* non-recursive */
low = 0; high = n-1;
while(low <= high){
   mid = (low + high)/2;
   if(number[mid] == data){ flag = 1; break; }
   else if(data < number[mid]) high = mid - 1;
   else low = mid + 1; }

/* recursive (Exercise 1) */
void bin_search(int a[], int data, int low, int high){
  int mid;
  if(low <= high){
     mid = (low + high)/2;
     if(a[mid] == data) printf("found at %d", mid+1);
     else if(data < a[mid]) bin_search(a, data, low, mid-1);
     else bin_search(a, data, mid+1, high);
  } else printf("not found"); }
Exercise 1: complexity। প্রতি call-এ সমস্যা অর্ধেক হয় এবং ১টি তুলনা লাগে: T(n) = T(n/2) + 1 ⇒ T(n) = O(log₂n)।

Exercise 3: x কতবার আছে ও প্রথম অবস্থান

count = 0; first = -1;
for(i = 0; i < n; i++){
   if(arr[i] == x){ count++; if(first == -1) first = i; } }
printf("%d বার, প্রথম index %d", count, first);
একবার পুরো array দেখতে হয় ⇒ O(n)। (Sorted হলে binary search দিয়ে প্রথম ও শেষ অবস্থান বের করে count = শেষ − প্রথম + 1; সময় O(log n)।)
Linear বনাম Binary: Linear — sorting লাগে না, ছোট/unsorted data-তে ভালো, best O(1), worst O(n)। Binary — sorted দরকার, বড় data-তে অনেক দ্রুত O(log n), array-তে (random access) কার্যকর, linked list-এ নয়।
