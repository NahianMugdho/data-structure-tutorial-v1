Sorting কী ও কেন?

Sorting হলো element-গুলোকে কোনো উদ্দেশ্যে নির্দিষ্ট ক্রমে (ছোট→বড় বা বর্ণানুক্রমে) সাজানো। অভিধানে শব্দ আর ফোন ডিরেক্টরিতে নাম বর্ণানুক্রমে থাকে বলেই খোঁজা সহজ। সাজানো data-তে Binary search চালানো যায়।

দুই ধরন: Internal sorting — সব element main memory-তে। External sorting — কিছু element secondary storage-এ (যেমন Merge sort বিশাল ফাইলে)। এই পেজে internal sorting।
আমরা যা শিখব: Bubble · Selection · Insertion · Quick · Merge · Heap। প্রতিটির জন্য: ধারণা → ধাপে ধাপে হিসাব (program দিয়ে তৈরি) → code → complexity।

Bubble Sort

Array-কে বারবার পাশাপাশি দুটি দুটি করে তুলনা করা হয় (X[i] বনাম X[i+1]); ক্রম ভুল হলে অদলবদল (swap)। প্রতি pass-এ সবচেয়ে বড় মান “বুদবুদের মতো” ডানে ভেসে যায়। এর আরেক নাম exchange sort। n টি element-এ n−1 pass লাগে।

void bubblesort(int x[], int n){
  int i, j, temp;
  for(i = 0; i < n; i++)
    for(j = 0; j < n - i - 1; j++)
      if(x[j] > x[j+1]){ temp = x[j]; x[j] = x[j+1]; x[j+1] = temp; } }
Complexity: n−1 pass × প্রতি pass-এ ≈ n−1 তুলনা = (n−1)² = n²−2n+1 ⇒ O(n²)। (সঠিক গণনায় pass-এ তুলনা কমে বলে মোট n(n−1)/2।) Element বেশি হলে বহু অকার্যকর।

Selection Sort

প্রতি pass-এ বাকি অংশ থেকে সবচেয়ে ছোট element খুঁজে তাকে সামনের ঘরের সাথে swap করা হয়। Pass 1: x[0..n−1]-এর ক্ষুদ্রতম x[0]-এর সাথে swap; Pass 2: x[1..n−1]-এর ক্ষুদ্রতম x[1]-এর সাথে; … মোট (n−1) pass এবং সর্বোচ্চ n−1 swap।

void selectionSort(int low, int high){
  int i, j, temp, minindex;
  for(i = low; i <= high; i++){
     minindex = i;
     for(j = i+1; j <= high; j++)
        if(a[j] < a[minindex]) minindex = j;
     temp = a[i]; a[i] = a[minindex]; a[minindex] = temp; } }
Recursive রূপ: selectionSort(n) → x[n..]-এর ক্ষুদ্রতম খুঁজে x[n]-এর সাথে swap, তারপর selectionSort(n+1); n শেষ index-এ পৌঁছালে থামে। Complexity: O(n²), তবে swap কম — তাই insertion/bubble-এ অনেক swap লাগলে selection পছন্দের।

Insertion Sort

বামের অংশ sorted ধরে রাখা হয়। ডান থেকে একটি করে নতুন element (key) নিয়ে sorted অংশে সঠিক জায়গা খুঁজে ঢোকানো হয় — তাস সাজানোর মতো। যে element বড়, সে এক ঘর ডানে সরে।

Complexity: Best (প্রায় sorted) O(n), Average/Worst O(n²)। কখন ভালো: array-তে মাত্র কয়েকটি item জায়গার বাইরে থাকলে; live leaderboard-এর মতো প্রায় sorted data। এটি stable।

Quick Sort — Divide & Conquer

একটি pivot বেছে array-কে দুই ভাগে ভাগ করা হয়: pivot-এর চেয়ে ছোটগুলো বামে, বড়গুলো ডানে। তারপর দুই ভাগেই একই কাজ recursively করা হয়। সব ভাগ শেষ হলে পুরো array sorted।

partition() কীভাবে কাজ করে: pivot = প্রথম element। ‘up’ pointer বাম থেকে ডানে চলে pivot-এর চেয়ে বড় element খোঁজে; ‘down’ pointer ডান থেকে বামে চলে pivot-এর চেয়ে ছোট element খোঁজে। দুটিই পেলে (up < down) swap। up ও down পার হয়ে গেলে pivot ও a[down] অদলবদল — pivot তার চূড়ান্ত জায়গায়।
quicksort(p, q){ if(p < q){ j = PARTITION(a, p, q+1); quicksort(p, j-1); quicksort(j+1, q); } }
partition(a, m, p){ v = a[m]; up = m; down = p;
  do{ repeat up = up+1 until (a[up] >= v);
      repeat down = down-1 until (a[down] <= v);
      if(up < down) interchange(a, up, down);
  } while(up < down);
  a[m] = a[down]; a[down] = v; return down; }

Complexity: গড় ও best O(n log n); pivot যদি সবসময় সবচেয়ে ছোট/বড় হয় তবে worst O(n²)। ভালো pivot = median। অগোছালো data-য় সাধারণত সবচেয়ে দ্রুত। Quick sort stable নয়।

Merge Sort

Array-কে বারবার অর্ধেক করে ভাগ করা হয় যতক্ষণ না প্রতিটি ভাগে ১টি element; তারপর দুটি sorted অংশকে তুলনা করে merge করে বড় sorted অংশ বানানো হয়। প্রতিবার দুই অংশের সামনের element তুলনা করে ছোটটি নেওয়া হয়।

Complexity: সব ক্ষেত্রে O(n log n); বাড়তি O(n) memory লাগে; stable। বিশাল ফাইল (external sorting) ও library catalog-এ উপযোগী।

Heap Sort

Heap হলো complete binary tree। Max heap-এ root সবচেয়ে বড়। ধাপ: (১) array থেকে max heap বানাও। (২) root (সবচেয়ে বড়) শেষের ঘরে swap করো এবং heap-এর আকার ১ কমিয়ে heapify করো। (৩) পুরো array sorted না হওয়া পর্যন্ত চালাও। Heap নিয়ে বিস্তারিত: Tree পেজ।

Complexity: সব ক্ষেত্রে O(n log n); বাড়তি memory প্রায় লাগে না (in-place); stable নয়। Priority queue ও OS-এর task scheduling-এ heap ব্যবহৃত।
