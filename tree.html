Tree কী?

Tree একটি non-linear data structure যেখানে data hierarchical (উপর-নিচ ধাপে) সাজানো থাকে। ফোল্ডারের ভেতরে ফোল্ডার, পরিবারের বংশতালিকা — সবই tree। এটি recursive সংজ্ঞা: প্রতিটি child নিজেই একটি ছোট tree (subtree)।

Tree-র সংজ্ঞা (তিনভাবে): (১) Node ও edge দিয়ে গঠিত hierarchical structure। (২) Cycle ছাড়া connected graph। (৩) যে graph-এ যেকোনো দুই vertex-এর মধ্যে ঠিক একটি পথ আছে।

✘ Tree নয় — E-F যুক্ত হওয়ায় C,E,F cycle তৈরি করেছে।

✔ Tree — কোনো cycle নেই।

গুরুত্বপূর্ণ বৈশিষ্ট্য: প্রতি জোড়া vertex-এর মধ্যে একটাই পথ · n vertex হলে ঠিক n−1 edge · Graph tree ⇔ minimally connected · n vertex ও n−1 edge-এর যেকোনো connected graph একটি tree · cycle থাকবে না · root থেকে যেকোনো node-এ একটাই পথ।

Tree-র পরিভাষা (ইন্টারেক্টিভ)

নিচের tree-টি PDF-এর উদাহরণ। একটি পরিভাষার বোতাম চাপলে সংজ্ঞা আসবে এবং সংশ্লিষ্ট node হলুদ হবে।

একটি বোতাম বেছে নাও।

মনে রাখার নিয়ম: Depth = উপর থেকে নিচে গোনা (root=0); Height = নিচ থেকে উপরে গোনা (leaf=0)। Tree-র height = root-এর height = 3; Tree-র degree = সবচেয়ে বেশি degree = Degree(B) = 3। “Level” ও “depth” একই অর্থে ব্যবহৃত হয়। Level 0: A · Level 1: B,C · Level 2: G,I,H,E,F · Level 3: J,K,D।

Tree-র ধরন

General tree: child সংখ্যার কোনো সীমা নেই (ফোল্ডার, পরিবার)। Binary tree: প্রতি node-এ সর্বোচ্চ ২ child (left, right)। Binary tree-র বিশেষ রূপ:

Full/Strict (প্রতি node-এ 0 বা 2 child)
Perfect (সব internal node-এ 2 child, সব leaf একই level)
Complete/Almost complete (শেষ level বাদে পূর্ণ, শেষটি বাম থেকে)
Skewed (সবাই একদিকে, linked list-এর মতো, depth n−1)
Balanced: যেকোনো node-এ বাম ও ডান subtree-র height-এর পার্থক্য ≤ 1। Rooted binary tree: একটি root আছে এবং প্রতি node-এ ≤ 2 child। Labeled/Unlabeled: node-এ নাম থাকলে labeled।
সূত্র: n node-এর tree-তে n−1 edge · Height h-এ সর্বোচ্চ node = 2h+1−1 · Level k-এ সর্বোচ্চ 2k node · N level-এ সর্বোচ্চ 2N−1 · degree-2 node n₂ হলে leaf N₀ = n₂+1 · n leaf-এর full binary tree-এ মোট 2n−1 node · n unlabeled node-এ binary tree = 2nCn/(n+1) (n=3 ⇒ 5; labeled ⇒ 5×3! = 30; n=4 ⇒ 14)।

Binary Search Tree (BST)

BST হলো এমন binary tree যেখানে প্রতি node-এর বাম subtree-র সব মান তার চেয়ে ছোট, আর ডান subtree-র সব মান বড়। তাই খোঁজার সময় প্রতি ধাপে অর্ধেক বাদ পড়ে — গড়ে O(log n); tree একদিকে ঝুঁকে গেলে (skewed) O(n)।

উদাহরণ ১: 50,30,70,20,40,60,80
উদাহরণ ২ (ক্রমানুসারে insert): 50,70,60,20,90,10,40,100
Construct করার নিয়ম: প্রথম মান root; এরপর প্রতিটি মান root থেকে তুলনা করে নামতে নামতে ফাঁকা জায়গায় বসাও। উদাহরণ ২-এর inorder: 10,20,40,50,60,70,90,100 (সবসময় sorted)।
Search 40: 50-এ ছোট ⇒ বামে; 30-এ বড় ⇒ ডানে; 40 পেলাম। Insert 25: 50→বামে, 30→বামে, 20-এ বড় ⇒ 20-এর ডান child।
Delete-এর ৩ case: (১) Leaf — সরাও। (২) এক child — সেই child দিয়ে প্রতিস্থাপন। (৩) দুই child — ডান subtree-র সবচেয়ে ছোট (inorder successor) দিয়ে প্রতিস্থাপন করে সেটি delete। উদাহরণ: 30 মুছলে 40 ওর জায়গায় বসে।

BST ইন্টারেক্টিভ

কীভাবে চালাবে: সংখ্যা লিখে Insert দাও — tree নিজে সাজাবে। Search চাপলে খোঁজার পথ হলুদ হবে। Delete-এ তিন case-ই চলে। Preorder/Inorder/Postorder/Level চাপলে node-গুলো ক্রমানুসারে হলুদ হবে এবং ক্রম নিচে লেখা হবে।

Tree Traversal — প্রতিটি node ঠিক একবার ভিজিট

কোনো operation করতে আগে node-এ পৌঁছাতে হয়। ভিজিট করার ক্রম অনুযায়ী চারটি পদ্ধতি; প্রথম তিনটি Depth First, শেষটি Breadth First (queue ব্যবহার করে)।

পদ্ধতিক্রমফল (বামের tree)
PreorderRoot → Left → Right1,2,4,5,3,6
InorderLeft → Root → Right4,2,5,1,3,6
PostorderLeft → Right → Root4,5,2,6,3,1
Level orderস্তর ধরে বাম→ডান1,2,3,4,5,6
Level order: root queue-তে রাখো → queue থেকে একটি node তুলে ভিজিট করো, তার child-দের queue-তে দাও → queue খালি না হওয়া পর্যন্ত।
ব্যবহার: BST-এর inorder = sorted output · Preorder থেকে expression-এর prefix, Postorder থেকে postfix · Postorder: tree মুছে ফেলতে · Level order: স্তরভিত্তিক কাজ · দুই traversal (inorder + preorder/postorder) থেকে tree পুনর্গঠন সম্ভব। উদাহরণ: Postorder = D B E C A, Inorder = D B A E C ⇒ root A (postorder-এর শেষ), বাম = {D,B}, ডান = {E,C} ⇒ Preorder = A B D E C।

Expression Tree

Operator হলো internal node, operand হলো leaf। Tree-র inorder দিলে infix, preorder দিলে prefix, postorder দিলে postfix expression পাওয়া যায়।

(a+b)/(a*b−c)+d
(5+3)*2
Infix: (a+b)/(a*b−c)+d · Prefix: + / + a b − * a b c d · Postfix: a b + a b * c − / d +। (5+3)*2: আগে 5+3=8, তারপর 8×2 = 16।

Heap (Min Heap ও Max Heap)

Heap একটি complete binary tree (শেষ level বাদে পূর্ণ, শেষটি বাম থেকে ভরা) যা priority queue ও heap sort-এ ব্যবহৃত হয়। Min heap: প্রতি parent ≤ তার child, তাই root = সবচেয়ে ছোট। Max heap: প্রতি parent ≥ child, root = সবচেয়ে বড়।

Insert: সবচেয়ে নিচের স্তরে বামদিকের ফাঁকা জায়গায় বসাও, তারপর parent-এর সাথে তুলনা করে উপরে ওঠাও (heapify-up) — O(log n)। Remove min/max: root সরাও, শেষ node root-এ আনো, নিচে নামাও (heapify-down) — O(log n)। Peek: root দেখা — O(1)।
Heap sort: (১) max heap বানাও (২) root (সবচেয়ে বড়) শেষের ঘরে সরাও ও heap ছোট করে heapify করো (৩) পুরো array sorted না হওয়া পর্যন্ত চালাও — O(n log n)। Array সূত্র (0-index): parent = ⌊(i−1)/2⌋, বাম child = 2i+1, ডান child = 2i+2।

void inorder(node *r){ if(r){ inorder(r->left); printf("%d ",r->data); inorder(r->right);} }
void preorder(node *r){ if(r){ printf("%d ",r->data); preorder(r->left); preorder(r->right);} }
void postorder(node *r){ if(r){ postorder(r->left); postorder(r->right); printf("%d ",r->data);} }

struct node *search(struct node *n,int key){      // BST search
  if(n==NULL||n->key==key) return n;
  return keykey ? search(n->left,key) : search(n->right,key); }
struct node *insert(struct node *n,int key){      // BST insert
  if(n==NULL) return newNode(key);
  if(keykey) n->left=insert(n->left,key); else n->right=insert(n->right,key);
  return n; }
int getLeafCount(Node *n){ if(!n) return 0; if(!n->left&&!n->right) return 1;
  return getLeafCount(n->left)+getLeafCount(n->right); }
int countnodes(struct node *r){ return r? 1+countnodes(r->left)+countnodes(r->right):0; }
int maxDepth(struct node *n){ if(!n) return 0; int l=maxDepth(n->left),r=maxDepth(n->right); return (l>r?l:r)+1; }
bool isBST(Node *n,int lo,int hi){ if(!n) return true; if(n->data<lo||n->data>hi) return false;
  return isBST(n->left,lo,n->data)&&isBST(n->right,n->data,hi); }
int kthSmallest(Node *r,int *i,int k){ /* inorder-এ k-তম node */
  if(!r) return INT_MAX; int L=kthSmallest(r->left,i,k); if(L!=INT_MAX) return L;
  if(++*i==k) return r->data; return kthSmallest(r->right,i,k); }
সব function-ই recursion ব্যবহার করে — base case: node NULL। Inorder traversal করলে BST-এর মান ascending ক্রমে আসে, তাই k-তম ছোট মান পেতে k-তম node-এ থামলেই হয়।
