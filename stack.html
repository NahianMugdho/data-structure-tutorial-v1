Stack কী?

Stack একটি Abstract Data Type (ADT)। বাস্তবের স্তূপের মতো — তাসের ডেক বা থালার স্তূপ: নতুন থালা শুধু উপরে রাখা যায়, আবার তোলাও যায় শুধু উপর থেকে। Stack-এও সব operation এক প্রান্ত (top) থেকে হয়; যেকোনো সময় শুধু top element-টাই পাওয়া যায়।

LIFO = Last In First Out: যে element সবার শেষে ঢুকেছে সেটিই সবার আগে বের হয়। ঢোকানোর operation = PUSH, সরানোর operation = POP। (ভুল নাম: FIFO — সেটি Queue-র; Stack-এর অন্য নাম LIFO list, Pile, Push-down list।)

Stack-এর operation ও implementation

Stack বানানো যায় Array, Structure, Pointer বা Linked list দিয়ে; আকার স্থির (fixed) বা প্রয়োজনে বাড়ানো (dynamic) হতে পারে। Array দিয়ে বানালে আকার স্থির।

Operationকাজ
push()element stack-এ রাখা (storing)
pop()top element সরানো/পাওয়া (accessing)
peek()সরানো ছাড়া শুধু top দেখা
isFull()stack পূর্ণ কি না (পূর্ণে push ⇒ Overflow)
isEmpty()stack খালি কি না (খালিতে pop ⇒ Underflow)
int stack[MAXSIZE]; int top = -1;
int isempty(){ return top == -1; }        int isfull(){ return top == MAXSIZE-1; }
int peek(){ return stack[top]; }
int pop(){  if(!isempty()) return stack[top--]; else printf("Stack is empty"); }
void push(int d){ if(!isfull()) stack[++top] = d; else printf("Stack is full"); }
Linked list দিয়ে stack বানালে push করলে নতুন node list-এর সামনে (head-এ) বসে এবং pop-ও head থেকে — দুটিই O(1)। Array stack-এও push/pop O(1)।

কীভাবে চালাবে: সংখ্যা লিখে Push দাও, Pop/Peek করো। ৫টি ভরলে Push-এ Overflow, খালি থাকলে Pop-এ Underflow বার্তা আসবে। সবচেয়ে উপরেরটিই আগে বের হয় — LIFO।

Infix, Prefix, Postfix ও Expression

Infix: A+B (operator মাঝে) · Prefix: +AB · Postfix: AB+। Postfix-এ বন্ধনী ও precedence লাগে না — তাই কম্পিউটার সহজে মান বের করে। Precedence: ^ > * / > + −।

Infix → Postfix (stack দিয়ে): operand হলে সরাসরি output-এ; ( হলে push; ) হলে ( পর্যন্ত pop করে output-এ; operator হলে stack-এর top-এর precedence সমান/বেশি থাকলে আগে pop করে output-এ, তারপর নিজে push; শেষে বাকি সব pop।
Postfix মান নির্ণয়: operand হলে push; operator হলে দুটি pop (দ্বিতীয়টি ডানের operand), অপারেশন করে ফল push। শেষে stack-এ একটিই মান থাকে।

Queue — FIFO

Queue-তে নতুন element পিছনে (rear) ঢোকে (enqueue) এবং সামনে (front) থেকে বের হয় (dequeue) — টিকিট কাউন্টারের লাইনের মতো। First In First Out। Stack-এ একই প্রান্তে ঢোকা-বেরোনো, Queue-তে দুই প্রান্তে।

বাংলায় ব্যাখ্যা: Enqueue চাপলে নতুন সংখ্যা ডানে (rear) যুক্ত হয়; Dequeue চাপলে সবচেয়ে বাম (front) সংখ্যা বেরিয়ে যায়।
অন্যান্য queue: Circular queue (array শেষ হলে শুরুতে ঘোরে; পূর্ণ: (rear+1)%n == front), Deque (দুই প্রান্তেই insert/delete), Priority queue (heap দিয়ে; সবচেয়ে বেশি অগ্রাধিকার আগে)। BFS-এ queue, DFS-এ stack।

ধাঁধা: P, Q, R, S, T

পাঁচটি item P,Q,R,S,T একে একে stack-এ push হলো। stack ৪ বার pop করে প্রতিটি queue-তে ঢোকানো হলো। queue থেকে ২টি delete করে stack-এ push করা হলো। এখন stack থেকে ১টি pop — কোনটি?
