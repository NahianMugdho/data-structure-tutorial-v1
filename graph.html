Graph — মৌলিক ধারণা

Graph = vertex (node)-এর সেট + তাদের যুক্তকারী edge-এর সেট। Tree-র বিপরীতে graph-এ cycle থাকতে পারে। Tree হলো এমন graph যা connected ও cycle-হীন (n vertex ⇒ n−1 edge)।

BFS ও DFS

কীভাবে চালাবে: বোতাম চাপলে A থেকে শুরু করে node-গুলো ক্রমানুসারে হলুদ হবে এবং ক্রম নিচে লেখা হবে। BFS কাছের প্রতিবেশীদের আগে (queue); DFS একটি পথে যতদূর যায়, শেষ হলে ফিরে অন্য পথে (stack/recursion)।

Shortest Path — Dijkstra

Single source shortest path: এক উৎস (A) থেকে বাকি সব vertex-এ সবচেয়ে কম খরচের পথ। নেগেটিভ weight চলবে না। কৌশল (greedy): অনির্ধারিত vertex-দের মধ্যে যার দূরত্ব সবচেয়ে কম সেটিকে চূড়ান্ত করো, তার প্রতিবেশীদের দূরত্ব ছোট হলে আপডেট (relax) করো।

কীভাবে চালাবে: “পরের ধাপ” চাপো; হলুদ node = চূড়ান্ত হওয়া; নিচের টেবিলে প্রতিটি vertex-এর বর্তমান দূরত্ব; হলুদ edge = এখন পর্যন্ত পাওয়া shortest-path tree।
Complexity: array দিয়ে O(V²); min-heap দিয়ে O((V+E) log V)। BFS দিয়েও unweighted graph-এ shortest path হয়, কিন্তু weighted-এ Dijkstra লাগে।

Bellman-Ford ও SPFA

Bellman-Ford single-source shortest path, যেখানে edge-এর weight নেগেটিভ হতে পারে। পদ্ধতি: (V−1) বার সব edge relax করো। নেগেটিভ cycle থাকলে shortest path অর্থহীন (V-তম বারেও কমলে নেগেটিভ cycle ধরা পড়ে)। Complexity O(V·E)।

SPFA (Shortest Path Faster Algorithm): Bellman-Ford-এরই queue-ভিত্তিক দ্রুত রূপ — শুধু যে vertex-এর দূরত্ব বদলেছে তাদের queue-তে রেখে relax করে। single-source; গড়ে খুব দ্রুত, তাত্ত্বিক worst case O(V·E)।

Floyd-Warshall — সব জোড়ার shortest path

All-pairs shortest path, Dynamic Programming দিয়ে। প্রতিটি vertex k-কে “মাঝের স্টেশন” ধরে পরীক্ষা: d[i][j] = min(d[i][j], d[i][k] + d[k][j])। Complexity O(V³)।

কীভাবে চালাবে: “পরের k” চাপলে একটি করে vertex মাঝের স্টেশন হিসেবে যুক্ত হবে এবং কমে যাওয়া দূরত্ব হলুদ হবে। (উপরের graph, undirected)

Minimum Spanning Tree (MST)

Spanning tree: সব vertex যুক্ত অথচ cycle-হীন subgraph (V−1 edge)। MST: weighted graph-এ মোট weight সবচেয়ে কম spanning tree। নেটওয়ার্কে loop আটকাতে (spanning tree protocol) ও কম খরচে তার/পাইপ টানতে ব্যবহৃত।

Kruskal (greedy): সব edge weight অনুযায়ী ছোট→বড় সাজাও; একে একে নাও, তবে cycle তৈরি হলে বাদ দাও। V−1 edge হলে শেষ। Complexity O(E log E)।
Prim (greedy): একটি vertex থেকে শুরু; প্রতিবার ইতোমধ্যে নেওয়া অংশ থেকে বেরোনো সবচেয়ে সস্তা edge নাও। Complexity O(V²) বা heap-এ O(E log V)।
কীভাবে চালাবে: Kruskal/Prim বোতাম চাপলে একটি করে edge বিবেচনা হয় — সবুজাভ হলুদ = নেওয়া হলো, নিচের লেখায় কেন নেওয়া/বাদ দেওয়া হলো তা থাকবে।
