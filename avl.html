AVL Tree — বাংলায় ধারণা

সাধারণ BST-তে sorted data দিলে tree একদিকে ঝুঁকে linked list হয়ে যায় (search O(n))। AVL tree প্রতিটি node-এর Balance Factor (BF) = height(বাম) − height(ডান) সবসময় −1, 0 বা +1 রাখে; এর বাইরে গেলেই rotation করে ঠিক করে। ফলে সব operation O(log n)।

অবস্থাসমাধান
BF=+2, বাম child-এর BF ≥ 0 (LL)Right rotate
BF=−2, ডান child-এর BF ≤ 0 (RR)Left rotate
BF=+2, বাম child-এর BF < 0 (LR)আগে বামে left rotate, তারপর right rotate
BF=−2, ডান child-এর BF > 0 (RL)আগে ডানে right rotate, তারপর left rotate
Delete: BST-এর মতোই মোছো (leaf / এক child / দুই child হলে inorder successor); তারপর উপরের দিকে প্রতিটি node-এ BF দেখে প্রয়োজনে rotation। Insert-এ সর্বোচ্চ ১টি rotation (বা double) লাগে, delete-এ একাধিক লাগতে পারে।

AVL (ইন্টারেক্টিভ)

কীভাবে চালাবে: 10, 20, 30 insert করলে RR rotation দেখবে। তারপর কিছু মান delete করে দেখো tree আবার balance হয় কি না। নিচের বার্তায় কোন rotation হলো লেখা থাকবে।
