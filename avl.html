AVL Tree — ধারণা ও Balance Factor

AVL tree হলো self-balancing binary search tree, যেখানে প্রতিটি node-এর Balance Factor (BF) সবসময় −১, ০ বা +১ থাকে। নাম এসেছে Georgy Adelson-Velsky ও Landis-এর নামে।

কেন লাগে? (দাঁড়িপাল্লার গল্প): সাধারণ BST-তে 10, 20, 30, 40 — sorted ডাটা দিলে tree একদিকে ঝুঁকে linked list হয়ে যায়, search হয় O(n)। AVL tree দাঁড়িপাল্লার মতো: কোনো node-এর এক পাশ অন্য পাশের চেয়ে ২ ধাপ ভারী হলেই সে ঘুরে (rotation) ভারসাম্য ফিরিয়ে আনে। তাই সব operation O(log n)।
BF = বাম subtree-র height − ডান subtree-র height
Leaf-এর height = ১, না থাকা node-এর height = ০। বৈধ মান শুধু −১, ০, +১।

উদাহরণ: tree 33(9(8, 21(11)), 53(61))

figure পড়ার নিয়ম: h = ওই node থেকে নিচের দিকে সবচেয়ে লম্বা পথে মোট node সংখ্যা (leaf-এর h = 1)। 🟠 কমলা পথ = root 33-এর বাম দিকের সবচেয়ে লম্বা পথ (9 → 21 → 11, মোট ৩)। 🟣 বেগুনি পথ = ডান দিকের সবচেয়ে লম্বা পথ (53 → 61, মোট ২)।

নিচ থেকে উপরে ধাপে ধাপে হিসাব

  1. Leaf (8, 11, 61): নিচে কোনো child নেই, বাম ০ − ডান ০ = BF 0।
  2. 21: বামে 11 আছে (height ১), ডানে কিছু নেই (০) → ১ − ০ = +1। 21-এর নিজের h = ২।
  3. 53: বামে কিছু নেই (০), ডানে 61 (১) → ০ − ১ = −1। h = ২।
  4. 9: বামে 8 (h ১), ডানে 21 (h ২) → ১ − ২ = −1। h = ৩।
  5. 33 (root): বামে 9 (h ৩), ডানে 53 (h ২) → ৩ − ২ = +1।

নিচের table-এ একই হিসাব সংক্ষেপে:

Nodeবাম heightডান heightBF
8, 11, 61 (leaf)০০০
21 (বামে 11)১০+১
9 (বামে 8, ডানে 21→11)১২−১
53 (ডানে 61)০১−১
33 (বাম ৩, ডান ২)৩২+১

সব BF −১..+১-এর মধ্যে, তাই এই tree balanced।

Rotation — AVL-এর আসল কৌশল

Rotation-এ কয়েকটা node-এর জায়গা বদলে tree-র আকার ঠিক করা হয়, কিন্তু BST-এর নিয়ম (বাম < root < ডান) ভাঙে না।

Left Rotate (ডান দিক ভারী হলে)

    x                y
   / \              / \
  α   y     →      x   γ
     / \          / \
    β   γ        α   β
  1. y = x-এর ডান child। y-এর বাম subtree (β) কে x-এর ডান child বানাও।
  2. x-এর parent p থাকলে p-এর যে পাশে x ছিল সেখানে y বসাও। p না থাকলে y-ই নতুন root।
  3. x কে y-এর বাম child বানাও।

Right Rotate (বাম দিক ভারী হলে)

      y            x
     / \          / \
    x   γ   →   α   y
   / \              / \
  α   β            β   γ
  1. x = y-এর বাম child। x-এর ডান subtree (β) কে y-এর বাম child বানাও।
  2. y-এর parent-এর জায়গায় x বসাও (parent না থাকলে x নতুন root)।
  3. y কে x-এর ডান child বানাও।
মনে রাখার কৌশল: যে পাশ ভারী, তার উল্টো দিকে ঘোরাও। ডান ভারী → Left rotate, বাম ভারী → Right rotate।

চারটি Case — কোনটায় কী করব

যে node-এর BF ±২ হয়েছে তাকে z বলি। z-এর ভারী পাশের child-এর BF দেখলেই case বোঝা যায়।

Caseচেনার উপায়সমাধান
LLz-এর BF = +২, বাম child-এর BF ≥ ০z-এ Right rotate
RRz-এর BF = −২, ডান child-এর BF ≤ ০z-এ Left rotate
LRz-এর BF = +২, বাম child-এর BF < ০ (ভিতরের বাঁক)আগে বাম child-এ Left rotate, তারপর z-এ Right rotate
RLz-এর BF = −২, ডান child-এর BF > ০আগে ডান child-এ Right rotate, তারপর z-এ Left rotate
Insert-এ নতুন node-এর পথ দেখেও case বোঝা যায় (বামে-বামে = LL, বামে-ডানে = LR…)। Delete-এ child-এর BF দেখেই ঠিক করতে হয়; child-এর BF = ০ হলে single rotation (LL বা RR)।
পরীক্ষার ৫ ধাপ: ১) BST-এর মতো insert/delete ২) নিচ থেকে উপরে BF হিসাব ৩) সবচেয়ে নিচের ±২ node z খোঁজো ৪) z-এর ভারী child-এর BF দেখে case ঠিক করো ৫) rotation করে আবার BF যাচাই।

Insert — ধাপে ধাপে

  1. BST-এর নিয়মে নামো: newKey < current হলে বামে, বড় হলে ডানে, খালি জায়গা না পাওয়া পর্যন্ত।
  2. সেখানে নতুন node বসাও (leaf, BF = ০)।
  3. নিচ থেকে root পর্যন্ত সব node-এর height ও BF নতুন করে হিসাব করো।
  4. প্রথম যে node-এর BF ±২ হয় সেটাই z; case অনুযায়ী rotation করো।
  5. Insert-এ একটা rotation (বা double rotation) করলেই পুরো tree ঠিক হয়।
উদাহরণ: tree = 33(13(11(8), 21), 53(61)), insert করব 9।
9 < 33 → বামে; 9 < 13 → বামে; 9 < 11 → বামে; 9 > 8 → 8-এর ডানে বসে। এখন 11-এর BF = +২, বাম child 8-এর BF = −১ (< ০) → LR case। 8-এ Left rotate (9 উপরে আসে), তারপর 11-এ Right rotate। ফলে 9 হয় subtree-র root, বামে 8, ডানে 11।
👉 পরের স্লাইডে ▶ বাটনে অ্যানিমেশন দেখো।

Delete — ধাপে ধাপে

  1. BST-এর মতো যে node মুছবে তাকে খুঁজে বের করো।
  2. (ক) leaf হলে সরাসরি মোছো। (খ) এক child থাকলে child-কে তার জায়গায় বসাও। (গ) দুই child থাকলে ডান subtree-র সবচেয়ে ছোট মান (inorder successor) এখানে কপি করে successor node মুছো।
  3. নিচ থেকে root পর্যন্ত BF নতুন করে হিসাব করো।
  4. যেখানে BF ±২, সেখানে case অনুযায়ী rotation করো। Delete-এ একাধিক node-এ rotation লাগতে পারে।
উদাহরণ: tree = 33(13(9(8,11), 21), 53(61)), delete করব 13 (দুই child)।
Successor = ডান subtree-র সবচেয়ে ছোট = 21। 13-এর জায়গায় 21 বসে, পুরোনো 21 মুছে যায়। এখন নতুন 21-এর বাম height ২, ডান ০ → BF = +২; বাম child 9-এর BF = ০ (≥ ০) → LL case → Right rotate। শেষে 9 root, বামে 8, ডানে 21 (তার বামে 11)।

AVL (ইন্টারেক্টিভ অ্যানিমেশন)

রঙ: 🟠 খোঁজার পথ, 🟢 নতুন বা successor node, 🔴 unbalanced node (z)। প্রতিটি node-এর উপরে BF লেখা। নিচের লেখায় কী হচ্ছে বলা থাকবে।
