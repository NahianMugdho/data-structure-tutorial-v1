Linked List কী?

Array-তে element পাশাপাশি ঘরে থাকে; Linked list-এ প্রতিটি node-এ দুটি অংশ: data ও পরের node-এর ঠিকানা (next pointer)। শেষ node-এর next = NULL। শুরুর node-কে ধরে রাখে head। ফলে memory-তে ছড়ানো থাকলেও শিকলের মতো যুক্ত থাকে।

ধরন: Singly (শুধু next), Doubly (prev ও next — প্রতি node-এ ২টি pointer), Circular (শেষ node-এর next = প্রথম node)।

C কোড অ্যানিমেশন: ধাপে ধাপে

কীভাবে দেখবে: "পরে" চাপলে একটা করে লাইন চলবে, "অটো প্লে" দিলে নিজে নিজে চলবে, নিচের স্লাইডার টেনে যেকোনো ধাপে যাওয়া যায়। ডানে কোন লাইন চলছে, বামে মেমোরিতে node ও পয়েন্টারের অবস্থা, আর নিচে টার্মিনালের আউটপুট একসাথে বদলাবে।
রঙের মানে: বেগুনি = head, সবুজ = list এর node, হলুদ = এইমাত্র malloc হওয়া node, ধূসর ড্যাশ = list থেকে বাদ পড়া node, লাল = free হয়ে যাওয়া node, কমলা তীর = h, t, n পয়েন্টার।

পুরো C কোড দেখো 
#include <stdio.h>
#include <stdlib.h>

struct node {
    int data;
    struct node *next;
};

void insertHead(struct node **h, int v) {
    struct node *n = malloc(sizeof *n);
    if (n == NULL) {
        printf("Memory allocation failed!\n");
        return;
    }
    n->data = v;
    n->next = *h;
    *h = n;
    printf("%d inserted successfully!\n", v);
}

void deleteValue(struct node **h, int v) {
    while (*h && (*h)->data != v) {
        h = &(*h)->next;
    }
    if (*h) {
        struct node *t = *h;
        *h = t->next;
        free(t);
        printf("%d deleted successfully!\n", v);
    } else {
        printf("%d not found!\n", v);
    }
}

void display(struct node *h) {
    printf("Linked List: ");
    while (h != NULL) {
        printf("%d -> ", h->data);
        h = h->next;
    }
    printf("NULL\n");
}

void freeList(struct node **h) {
    while (*h) {
        struct node *t = *h;
        *h = t->next;
        free(t);
    }
}

int main() {
    struct node *head = NULL;
    insertHead(&head, 30);
    insertHead(&head, 20);
    insertHead(&head, 10);
    display(head);
    deleteValue(&head, 20);
    display(head);
    insertHead(&head, 5);
    display(head);
    freeList(&head);
    return 0;
}

Doubly ও Circular Linked List

কীভাবে দেখবে: উপরের বোতাম দিয়ে Doubly বা Circular বাছো, তারপর "পরে" চাপো বা অটো প্লে দাও। কমলা মোটা তীর মানে ওই ধাপে সেই পয়েন্টারটা বদলাল। নীল তীর = next, বেগুনি তীর = prev, হলুদ node = এইমাত্র malloc হওয়া, ধূসর = list থেকে বাদ পড়া, লাল = free হয়ে যাওয়া।

Doubly linked list: প্রতিটি node এ দুটো পয়েন্টার, prev (পেছনের node) আর next (সামনের node)। প্রথম node এর prev এবং শেষ node এর next = NULL। সুবিধা: পেছনে যাওয়া যায়, আর কোনো node এর পয়েন্টার জানা থাকলে delete O(1) (আগের node খুঁজতে হাঁটতে হয় না)। অসুবিধা: প্রতি node এ বাড়তি পয়েন্টারের মেমোরি, আর insert/delete এ দুই দিকের পয়েন্টার সামলাতে হয়।

struct dnode {
    int data;
    struct dnode *prev;
    struct dnode *next;
};

// a এর ঠিক পরে নতুন node বসানো
void insertAfter(struct dnode *a, int v) {
    struct dnode *n = malloc(sizeof *n);
    n->data = v;
    n->next = a->next;                 // ১. নতুন node এর next
    n->prev = a;                       // ২. নতুন node এর prev
    if (a->next) a->next->prev = n;    // ৩. পরের node এর prev
    a->next = n;                       // ৪. a এর next সবার শেষে
}

// p কে সরাসরি মোছা, আগের node খুঁজতে হাঁটতে হয় না
void deleteNode(struct dnode **head, struct dnode *p) {
    if (p->prev) p->prev->next = p->next;
    else *head = p->next;              // p নিজেই head ছিল
    if (p->next) p->next->prev = p->prev;
    free(p);
}

// tail থেকে উল্টো দিকে প্রিন্ট
void printBackward(struct dnode *tail) {
    for (struct dnode *c = tail; c; c = c->prev)
        printf("%d ", c->data);
}
মনে রাখো: insert এ আগে নতুন node এর দুই লিংক ঠিক করতে হয় (১, ২), তারপর পুরনো node গুলো বদলাতে হয় (৩, ৪)। a->next = n আগে করলে পরের node এর ঠিকানা হারিয়ে যায়।

Circular linked list: শেষ node এর next NULL না হয়ে আবার প্রথম node কে ধরে, ফলে শিকলটা বৃত্ত। এখানে head এর বদলে tail পয়েন্টার রাখা হয়, কারণ tail->next ই হলো head। তাতে শুরু ও শেষ দুই জায়গাতেই insert O(1)। ব্যবহার: round-robin scheduling, music playlist এর repeat mode।

struct cnode {
    int data;
    struct cnode *next;
};

// শেষে insert (tail পয়েন্টার বদলায়)
void insertEnd(struct cnode **tail, int v) {
    struct cnode *n = malloc(sizeof *n);
    n->data = v;
    if (*tail == NULL) {            // list খালি
        n->next = n;                // নিজেই নিজেকে ধরে
        *tail = n;
    } else {
        n->next = (*tail)->next;    // নতুন node এর next = head
        (*tail)->next = n;          // পুরনো tail এর next = নতুন node
        *tail = n;                  // tail সরলো
    }
}

// do-while, কারণ NULL এ কখনো পৌঁছানো যায় না
void display(struct cnode *tail) {
    if (!tail) return;
    struct cnode *c = tail->next;   // head থেকে শুরু
    do {
        printf("%d -> ", c->data);
        c = c->next;
    } while (c != tail->next);      // আবার head এ ফিরলে থামো
}
ফাঁদ: সাধারণ list এর মতো while (c != NULL) দিলে লুপ কখনো থামবে না। তাই head এর সাথে তুলনা করে থামতে হয়।

2D Array-র ঠিকানা (Row-major / Column-major)

Array memory-তে এক লাইনে থাকে। দুই-মাত্রার array R×C-কে সারি ধরে (row-major) বা কলাম ধরে (column-major) সাজানো যায়:

Row-major: ঠিকানা = Base + size × (i × C + j) · Column-major: ঠিকানা = Base + size × (j × R + i) (i, j = 0 থেকে শুরু)।

R C element size Base i j

Array বনাম Linked list: ঠিকানা কীভাবে পাই?

উপরের 2D array স্লাইডের হিসাবটা linked list এর অংশ নয়, বরং linked list কেন আলাদা সেটা বোঝার তুলনা।

Array: সব element মেমোরিতে গায়ে গায়ে থাকে, তাই i-তম element এর ঠিকানা সূত্রে এক ধাপে বের হয়: Base + size × i। 2D তে row-major এ Base + size × (i × C + j)। উপরের উদাহরণে 4040 বা 2840 একটা হিসাবেই পাওয়া গেছে, কোনো লুপ লাগেনি। তাই access O(1)।
Linked list: প্রতিটি node malloc দিয়ে মেমোরির যেকোনো জায়গায় তৈরি হয় (যেমন 0x1A0, 0x2B0, 0x3C0), ব্যবধানের কোনো নিয়ম নেই। তাই সূত্র খাটে না। ঠিকানা কেবল আগের node এর next এর ভেতরে লেখা থাকে। i-তম node এ যেতে head থেকে i ধাপ হাঁটতে হয়, তাই access O(n)।
